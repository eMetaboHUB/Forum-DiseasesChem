## BuildFORUMChemont

Association construction of compound CID (PubChem) with ChemOnt ontology identifiers. This construction utilizes the 
'Classifire_file.jar' instead of the ChemOnt REST API.

### Usage

```bash
amm buildChemontForum.sc <virtuoso-directory> <forum-release> <directory/pc_descr_canSMILES_value_*.gz>
```
